## 📖 프로젝트 주제
**서울시 에너지 사용 탄소 배출 예측과 따릉이 탄소 절감 효과 분석**

- 전기·가스 사용에 따른 온실가스 배출량의 **시계열 패턴을 분석**
- SARIMA 모델로 **2025~2026년 탄소 배출량을 예측**
- 따릉이 이용 건수를 예측해 **탄소 절감 효과를 정량화**

---

## 1. Project Overview

- **주제**: 전기·가스 사용으로 인한 탄소 배출 전망과 따릉이의 탄소 절감 기여도 분석
- **분석 대상**: 서울시 전기·가스 온실가스 배출량, 따릉이 이용 건수
- **문제 유형**: 시계열 분석(Time Series Forecasting)
- **핵심 목표**
  - 탄소 배출 패턴 분석
  - 시계열 모델 기반 미래 예측
  - 따릉이 탄소 절감량 정량화와 정책적 인사이트 도출

---

## 2. Data Description

| 데이터 | 기간 | 출처 |
|---|---|---|
| 전기 사용 온실가스 배출량 (월별, tCO₂) | 2018.01 ~ 2024.12 (84개월) | 서울특별시 에너지 통계 |
| 가스 사용 온실가스 배출량 (월별, tCO₂) | 2018.01 ~ 2024.12 (84개월) | 서울특별시 에너지 통계 |
| 따릉이 이용 건수·이동거리·탄소량 (월별) | 2017.01 ~ 2024.12 (96개월) | 서울 열린데이터광장, 서울특별시 공공자전거 이용정보(월별) |

> ※ 전기·가스 원본 데이터(연도별 엑셀 14개)는 `Data/` 폴더에 포함되어 있습니다.
> ※ 따릉이 원본은 용량이 커서 제외했고, `bike_preprocess.py`로 월별 집계한 `Data/bike_monthly.csv`를 포함했습니다.

**따릉이 전처리**
- 연도마다 다른 인코딩(utf-8 / cp949), 파일 형식(csv / xlsx), 컬럼명, 날짜 형식을 통일
- 결측 표기(`\N`)는 주로 성별 컬럼에 있고 이용 건수에는 결측이 없어, 행을 삭제하지 않고 월별로 합산

## 3. Problem Definition

- **배경**: 전기·가스는 삶에 필수적인 에너지이지만, 사용 과정에서 많은 탄소가 발생
- **문제 정의**: 전기·가스 배출량이 앞으로 어떻게 변할지 예측하고, 그 추세만으로 탄소중립에 충분한지 판단
- **가설**: 에너지 사용이 늘어 탄소 배출량은 증가할 것이다
- **대안 분석**: 행동 기반 감축 수단인 따릉이의 이용 건수와 탄소 절감량을 예측

---

## 4. Data Analysis Process

### 1) 시계열 구조 분석
- 추세(Trend)와 계절성(Seasonality) 확인
- 전기는 여름, 가스는 겨울에 최고치를 보이는 12개월 주기 계절성
- ACF / PACF 시각화로 패턴 분석

### 2) 정상성 검정
- ADF Test (귀무가설: 단위근이 있다 = 비정상)
- KPSS Test (귀무가설: 정상)

👉 두 검정으로 교차 확인 후 변환·차분 수행

| 계열 | 변환·차분 |
|---|---|
| 전기 | 1차 차분 + 계절 차분(12개월) |
| 가스 | 로그 변환 + 1차 차분 + 계절 차분(12개월) |
| 따릉이 | 로그 변환 + 계절 차분(12개월) + 1차 차분 |

---

### 3) 모델링

- **SARIMA (Seasonal ARIMA)** 모델 적용
- ACF / PACF로 후보를 보고 auto_arima(AIC 기준)로 차수 선택

| 계열 | 최종 모델 |
|---|---|
| 전기 | SARIMA(0,1,0)(0,1,2)₁₂ |
| 가스 | 로그 변환 후 SARIMA(0,1,2)(0,1,1)₁₂ |
| 따릉이 | 로그 변환 후 SARIMA(0,1,1)(1,1,0)₁₂ |

- 포트만토(Ljung-Box), Jarque-Bera 검정으로 잔차 진단
  - 가스·따릉이: 모든 시차(lag 1~24)에서 잔차 자기상관 없음, 정규성 만족
  - 전기: 계절 시차(lag 12·24)에서는 통과, 단기 시차(lag 2~4)에 약한 자기상관이 남음

---

### 4) 시계열 예측

- 2025 ~ 2026년(24개월) 예측, 95% 신뢰구간 포함
- 데이터가 7~8년치라 예측 기간은 계절 주기 2바퀴(24개월)로 제한

---

### 5) 따릉이 탄소 절감량 계산

- 월별 CO₂ 절감량(kg) = 예측 이용 건수 × 건당 평균 이동거리 **2.89km** × **0.232kg/km**
- 건당 평균 이동거리: 2017~2024년 전체 이동거리 ÷ 전체 이용 건수
- 0.232kg/km: 일반 승용차(2,000cc급, 휘발유, 연비 10km/L)를 대체할 때의 CO₂ 감소량 (에너지관리공단 수송에너지 계산식)
- 원본 데이터의 `탄소량` 컬럼도 같은 계수(이동거리 × 0.232)로 계산되어 있음을 확인

---

## 5. 분석 결과

### 과거 실측 (2018 → 2024)
- 전기: 1,961만 → 2,079만 tCO₂ (**+6.0%**)
- 가스: 946만 → 824만 tCO₂ (**-12.9%**)
- 전기 증가분과 가스 감소분이 상쇄되어 합계는 2,907만 → 2,904만 tCO₂로 **정체**
- 따릉이: 503만 건(2017) → 4,385만 건(2024), 2017~2022 누적 탄소 절감 **97,858 tCO₂**

### 예측 (2025 ~ 2026)

| 연도 | 전기 배출 | 가스 배출 | 따릉이 이용 | 따릉이 절감 | 절감 / 배출 |
|---|---|---|---|---|---|
| 2024 (실측) | 2,079만 t | 824만 t | 4,385만 건 | 23,894 t | 0.08% |
| 2025 (예측) | 2,040만 t | 795만 t | 4,706만 건 | 31,512 t | 0.11% |
| 2026 (예측) | 2,023만 t | 773만 t | 4,849만 건 | 32,475 t | 0.12% |

- 전기: 2024년 배출 감소가 반영되어 2,000만 tCO₂ 수준에서 **정체**
- 가스: 계절성을 유지하며 **완만하게 감소**
- 따릉이: 이용 건수가 **꾸준히 증가**, 2025~2026 누적 절감 약 **6.4만 tCO₂** (전기·가스 배출의 약 0.11%)

---

## 6. Insight

### 📌 가설 검증
- "배출량은 증가할 것"이라는 가설은 **지지되지 않음**
- 다만 배출은 정체하거나 아주 느리게 줄어, 2026년에도 연 2,800만 tCO₂ 수준이 유지됨
- 👉 자연적인 감소만으로는 탄소중립에 부족하며, **추가 감축 수단이 필요**

### 🚲 친환경 교통 확대
- 따릉이 이용은 계속 늘어 탄소 절감량도 꾸준히 증가
- 다만 절감 규모는 에너지 배출의 약 0.1% 수준
- 👉 따릉이 하나로는 부족하며, 여러 감축 수단을 함께 활용해야 함

### ⚡ 에너지 효율 개선
- 전기는 여름, 가스는 겨울에 배출이 집중되므로 계절별 에너지 관리 전략 필요

---

## 7. Conclusion

- 전기·가스 배출은 과거 6년간 정체했고, 앞으로도 정체~완만한 감소가 예상됨
- 따릉이 같은 행동 기반 수단은 꾸준히 성장하지만 기여 규모는 작아, 설비 전환과 행동 유도 정책을 함께 추진해야 함

**한계와 발전 방향**
- SARIMA는 순수 시계열 모델이라 코로나19·날씨 같은 외생변수를 반영하지 못함 → ARIMAX 등으로 개선
- 최근 1년의 증감을 이어 가는 모델 구조라, 추세가 바뀌는 시기에는 예측 오차가 커질 수 있음 → 예측값보다 방향과 신뢰구간 범위로 해석
- 절감량 식은 따릉이 이용이 모두 자동차를 대체했다고 가정하며, 건당 이동거리가 해마다 줄고 있어 절감량이 과대평가될 수 있음
- 따릉이가 실제로 자동차 이용을 줄였는지는 인과적으로 확인하지 못함
- 데이터가 쌓이는 대로 재학습하고 예측과 실제를 비교할 필요가 있음
