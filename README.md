## 📖 프로젝트 주제
**서울시 에너지 사용 탄소 배출 예측과 따릉이 탄소 절감 효과 분석**

- 전기·가스 사용에 따른 온실가스 배출량의 **시계열 패턴을 분석**
- SARIMA 모델로 **2025~2026년 탄소 배출량을 예측**
- 따릉이 이용 건수를 예측해 **탄소 절감 효과를 정량화**

---

## 1. Project Overview

- **주제**: 전기·가스 사용으로 인한 탄소 배출 전망과 따릉이의 탄소 절감 기여도 분석
- **분석 대상**: 서울시 전기·가스 온실가스 배출량, 따릉이 이용 건수
- **문제 유형**: 시계열 분석(Time Series Forecasting)
- **핵심 목표**
  - 탄소 배출 패턴 분석
  - 시계열 모델 기반 미래 예측
  - 따릉이 탄소 절감량 정량화와 정책적 인사이트 도출

---

## 2. Data Description

| 데이터 | 기간 | 출처 |
|---|---|---|
| 전기 사용 온실가스 배출량 (월별, tCO₂) | 2018.01 ~ 2024.12 (84개월) | 서울특별시 에너지 통계 |
| 가스 사용 온실가스 배출량 (월별, tCO₂) | 2018.01 ~ 2024.12 (84개월) | 서울특별시 에너지 통계 |
| 따릉이 이용 건수·이동거리·탄소량 (월별) | 2017.01 ~ 2024.12 (96개월) | 서울 열린데이터광장, 서울특별시 공공자전거 이용정보(월별) |

> ※ 전기·가스 원본 데이터(연도별 엑셀 14개)와 따릉이 월별 집계는 `Data/` 폴더에 포함되어 있습니다.

- 결측 표기(`\N`)는 주로 성별 컬럼에 있고 이용 건수에는 결측이 없어, 행을 삭제하지 않고 월별로 합산

## 3. Problem Definition

- **배경**: 전기·가스는 삶에 필수적인 에너지이지만, 사용 과정에서 많은 탄소가 발생
- **문제 정의**: 전기·가스 배출량이 앞으로 어떻게 변할지 예측하고, 그 추세만으로 탄소중립에 충분한지 판단
- **가설**: 에너지 사용이 늘어 탄소 배출량은 증가할 것이다
- **대안 분석**: 행동 기반 감축 수단인 따릉이의 이용 건수와 탄소 절감량을 예측

---

## 4. Data Analysis Process

### 1) 시계열 구조 분석
- 추세(Trend)와 계절성(Seasonality) 확인
- 전기는 여름, 가스는 겨울에 최고치를 보이는 12개월 주기 계절성
- ACF / PACF 시각화로 패턴 분석

### 2) 정상성 검정
- ADF Test (귀무가설: 단위근이 있다 = 비정상)
- KPSS Test (귀무가설: 정상)

👉 세 계열 모두 로그 변환 후 12개월 계절 차분을 적용하고, 추가 1차 차분은 KPSS 검정 기준(`ndiffs`)으로 결정  
👉 필요 없는 차분까지 하면(과차분) 직전 해의 증감 추세를 미래로 계속 이어 가는 문제가 있어 최소한의 차분만 적용

| 계열 | 변환·차분 |
|---|---|
| 전기 | 로그 변환 + 계절 차분(12개월) |
| 가스 | 로그 변환 + 계절 차분(12개월) |
| 따릉이 | 로그 변환 + 계절 차분(12개월) + 1차 차분 |

- 가스는 원 단위 모델이 예측을 지나치게 가파르게 줄여 4년 예측 시 여름 값이 음수(2028.09)가 되는 문제가 있어 로그 변환이 필수

---

### 3) 모델링

- **SARIMA (Seasonal ARIMA)** 모델 적용
- 차분 횟수를 고정한 뒤 auto_arima(AIC 기준)로 차수 선택
- 원 발표 차수도 재현해 05장 백테스트에서 함께 비교

| 계열 | 최종 모델 | 원 발표 차수 |
|---|---|---|
| 전기 | 로그 SARIMA(1,0,2)(0,1,1)₁₂ | SARIMA(0,1,0)(0,1,2)₁₂ |
| 가스 | 로그 SARIMA(0,0,1)(0,1,1)₁₂ | SARIMA(0,1,0)(2,1,0)₁₂ |
| 따릉이 | 로그 SARIMA(2,1,2)(1,1,0)₁₂ | 로그 SARIMA(0,1,1)(1,1,0)₁₂ |

- 포트만토(Ljung-Box), Jarque-Bera 검정으로 잔차 진단
  - 세 모델 모두 lag 1~24에서 잔차 자기상관 없음, 정규성 만족

---

### 4) 예측 검증 (백테스트)

- 2020·2021·2022년 12월까지 학습 → 이후 24개월 예측 → 실제값과 비교
- 비교 기준선: 계절 단순예측(작년 같은 달 값을 그대로 사용)

| 계열 | 선택 모델 MAPE | 원 발표 차수 MAPE | 기준선 MAPE | 95% 구간 적중률 |
|---|---|---|---|---|
| 전기 | 6.3% | 12.2% | 5.7% | 84.7% |
| 가스 | 7.4% | 8.9% | 8.2% | 91.7% |
| 따릉이 | 20.3% | 22.5% | 24.4% | 100% |

- 세 계열 모두 선택 모델이 원 발표 차수보다 오차가 작음
- 원 발표 차수는 직전 해 증감을 이어 가 2021~2022년 증가기 이후를 크게 높게 예측
- 전기는 기준선과 비슷한 수준 → 전기 예측은 "현재 수준 유지" 정도로 해석
- 따릉이는 성장기에서 정체기로 바뀌는 구간이라 오차가 20%대 → 범위와 방향으로 해석

---

### 5) 시계열 예측

- 2025 ~ 2026년(24개월) 예측, 95% 신뢰구간 포함
- 데이터가 7~8년치라 예측 기간은 계절 주기 2바퀴(24개월)로 제한

---

### 6) 따릉이 탄소 절감량 계산

- 월별 CO₂ 절감량(kg) = 예측 이용 건수 × 건당 평균 이동거리 **2.36km** × **0.232kg/km**
- 건당 평균 이동거리: 최근 12개월(2024년) 전체 이동거리 ÷ 전체 이용 건수
  - 건당 거리는 2019년 5.0km → 2024년 2.4km로 해마다 줄고 있어, 전체 기간 평균(2.89km)을 쓰면 예측 첫해 절감량이 실측보다 30% 이상 뛰는 문제가 생김
- 0.232kg/km: 일반 승용차(2,000cc급, 휘발유, 연비 10km/L)를 대체할 때의 CO₂ 감소량 (에너지관리공단 수송에너지 계산식)
- 원본 데이터의 `탄소량` 컬럼도 같은 계수(이동거리 × 0.232)로 계산되어 있음을 확인
- 따릉이 이동이 모두 승용차를 대체했다고 가정한 값이라 실제 절감량의 **상한**에 가까움

---

## 5. 분석 결과

### 과거 실측 (2018 → 2024)
- 전기: 1,961만 → 2,079만 tCO₂ (**+6.0%**)
- 가스: 946만 → 824만 tCO₂ (**-12.9%**)
- 전기 증가분과 가스 감소분이 상쇄되어 합계는 2,907만 → 2,904만 tCO₂로 **정체**
- 따릉이: 503만 건(2017) → 4,385만 건(2024), 2017~2022 누적 탄소 절감 **97,858 tCO₂**

### 예측 (2025 ~ 2026)

| 연도 | 전기 배출 | 가스 배출 | 전기+가스 | 따릉이 이용 | 따릉이 절감 |
|---|---|---|---|---|---|
| 2024 (실측) | 2,079만 t | 824만 t | 2,904만 t | 4,385만 건 | 23,894 t |
| 2025 (예측) | 2,087만 t | 849만 t | 2,937만 t | 4,677만 건 | 25,586 t |
| 2026 (예측) | 2,088만 t | 851만 t | 2,938만 t | 4,798만 건 | 26,252 t |

- 전기·가스: 2,900만 tCO₂대에서 **정체**
- 따릉이: 이용 건수는 완만하게 증가, 2025~2026 누적 절감 약 **5.2만 tCO₂**

---

## 6. Insight

### 📌 가설 검증
- "배출량은 증가할 것"이라는 가설은 **확인되지 않음**
- 다만 줄어드는 흐름도 보이지 않아, 2026년에도 연 2,900만 tCO₂ 수준이 유지될 것으로 예상
- 👉 자연적인 감소만으로는 탄소중립에 부족하며, **추가 감축 수단이 필요**

### 🚲 친환경 교통 확대
- 따릉이 이용은 계속 늘어 탄소 절감량도 꾸준히 증가
- 따릉이는 **수송 부문**(승용차 대체) 감축이고, 전기·가스는 **건물 에너지** 배출이라 부문이 다름
- 전기·가스 배출 대비 비율(약 0.09%)은 규모를 가늠하기 위한 참고값이며, 따릉이 단독으로 에너지 배출 정체를 상쇄할 규모는 아님
- 👉 에너지 부문의 설비 전환·효율 개선과 수송 부문의 친환경 교통 확대를 함께 추진해야 함

### ⚡ 에너지 효율 개선
- 전기는 여름, 가스는 겨울에 배출이 집중되므로 계절별 에너지 관리 전략 필요

## 7. Conclusion

- 전기·가스 배출은 과거 7년간 정체했고, 앞으로 2년도 같은 수준이 예상됨
- 따릉이 같은 행동 기반 수단은 꾸준히 성장하지만 기여 규모는 작아, 설비 전환과 행동 유도 정책을 함께 추진해야 함

**한계와 발전 방향**
- SARIMA는 순수 시계열 모델이라 코로나19·날씨 같은 외생변수를 반영하지 못함 → ARIMAX 등으로 개선
- 전기 예측 오차는 계절 단순예측과 비슷한 수준이고, 따릉이는 추세 전환기라 오차가 20%대 → 예측값보다 방향과 신뢰구간 범위로 해석
- 절감량 식은 따릉이 이용이 모두 자동차를 대체했다고 가정한 상한값
- 따릉이가 실제로 자동차 이용을 줄였는지는 인과적으로 확인하지 못함
- 2025년 실측 데이터가 공개되면 예측과 실제를 비교해 재검증 필요
